# «Латунный янычар 2.0» — ОТЧЁТ ПРИЁМКИ АССЕТОВ (intake v1)
Итог: **принято 97 позиций, брак нарезки 0, недостача 1 (некритичная),
предупреждений 6**. Пакет готов к автономной сборке.

## 1. Конвейер (по sheets.json + дельте)
1. **Ключ**: адаптивный — правило `R>200 ∧ B>200 ∧ G<30` ∪ семплы четырёх
   углов листа ±30; белые линии/рамки сеток снимаются флудом от края
   (near-white проходим только по связности с краем — блики внутри
   объектов не тронуты). Маджента внутри объектов (сквозные дыры) — фон.
2. **Нарезка**: блоб-детекция (компоненты ≥600 px², row-major, сеточные
   блобы отбрасываются по span>60 %×60 % при fill<20 %); фолбэк — доли
   cols×rows с bbox не-фона в ячейке. Портреты — строго доли 4×2 / 2×2,
   карточки целиком (решение **D1 = вариант А**: художественные фоны
   карточек сохранены, ключ — только маджентовые скругления углов).
   Курсоры — доли без кропа (активная точка = левый-верх ячейки).
3. **Defringe + Despill-unmix**: розовая кайма перекрашивается по
   внутренним соседям; далее покомпонентный анмикс `t=(min(R,B)−G)/255`,
   восстановление fg=(rgb−t·маджента)/(1−t), t→прозрачность. Это вылечило
   принципиально смешанные зоны: **сетки сачков, линзу лупы, ореолы
   значка/короны/подарка, «юбку» банки смазки, замок zoom-масштаба**.
4. **Чистка мусора**: в катаутах остаются главная компонента + связные
   ≥2 % её площади (осколки рамок ячеек удалены; составные объекты —
   ключик с биркой, швабра с биркой — целы).
5. **Гирлянда**: ламп 32, медианный диаметр 45 px; белёсая дымка
   (α<200 ∧ S<25 % ∧ V>70 %) снята всюду, кроме внутреннего ореола ламп
   (R=0.75·d). Остались огни + провод — корректный оверлей.
6. **Fit**: contain + прозрачный паддинг в целевые размеры спеки;
   сцены — LANCZOS до 1920×1080.

## 3. Калибровка day/night офиса (выходная зона)
Фазовая корреляция: весь кадр (−6,−3, peak 0.014); правая треть
(−12,−10, 0.022); патч считывателя (−10,−9, 0.064); патч верха двери
(−27,0, 0.030). Пики <0.07 ⇒ расхождение **структурное** (разные
генерации), а не когерентный сдвиг — варп-edit дневного кадра
противопоказан (исказит фурнитуру). **Принятое решение**: движок v2
поддерживает раздельные якоря `pos_night / pos_day` для катаутов
выходной зоны (LED считывателя, LED/панель сигнализации, накладка
штока щитовой); позиции калибруются по обоим кадрам на сборке с
контрольной скрин-парой в гаунтлете. Требование дельты «сообщить в
отчёте» — выполнено.

## 4. Недостачи и исключения
- **st_plate_empty** — в N5-листе отсутствует. Некритично: крепёжная
  пластина запечена в катауте `st_wheel_wall` (самодостаточен), стены
  вайда чистые. Исключён из манифеста.
- **st_padlock** (вайд-масштаб) — исключён по дельте: замочек запечён
  в вайде подсобки (как рычаг насоса и красные вентили).

## 5. Канон интерпретации арта (обязателен для сборки)
Арт-вайды слегка разошлись со спекой §1 — по принципу «вайд статичен,
движок адаптируется» зафиксированы решения:
1. **Правый стол офиса = стол Иры**: на его тумбе нарисована кодовая
   панель (ящик Иры), ПК Иры = правый монитор (zoom_pc консистентен:
   копир слева в кадре ✓). **Левый стол = стол Лапидуса** (ящик без
   панели — поддевается линейкой; st_ruler_on_desk якорится на него).
2. **Узкая голубая дверь** правее главной = дверь щитовой: ручки нет,
   плоская накладка с квадратом — точное место `st_util_handle`.
3. **Главная дверь** — коричневая с табличкой, EXIT над ней; засов
   существует только в зуме (st_bolt_* на zoom_exit_door).
4. Простенок между дверями: **тёмная панель с экраном = сигнализация**
   (zoom_alarm, LED-плашки st_led_alarm_*); **круглая панелька правее
   голубой двери = считыватель** (круглые st_led_reader_* ✓ форма).
5. **KPI = маркерная доска** справа над зоной Иры; `st_pointer_on_board`
   якорится на её кромку.
6. **Маховик-«экспонат»**: стены чистые — `st_wheel_wall` (с пластиной
   в составе катаута) вешается между аквариумом и шкафом.
7. Подсобка: **сачок** (`st_net_on_top`) — на верхней кромке шкафа;
   **коробка НГ** живёт на **верхней полке стеллажа** («антресоль»,
   zoom_attic = край этой полки): до снятия в зуме рисуется уменьшенный
   `st_box_on_floor` на полке, после — он же на полу вайда; **швабра**
   (`st_mop_on_hook`) вешается на стену между шкафом и раковиной.
8. Вент-решётки: офис — над шкафом-гардеробом; подсобка — над шкафом
   уборщицы (сквозная пара ✓ соответствует GDD-ветке D1).
9. Красные вентили/рычаг насоса/замочек верстака запечены в вайде
   подсобки — весь интерактив стенда только в zoom_bench (катауты).
