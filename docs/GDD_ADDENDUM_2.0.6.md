## 1. Пространство: теперь 14 зумов (было 12)

Добавлены два полнокадровых зума открытых ящиков (р.19, «схема Лапидуса»):

| Новый зум | Родитель | Открывается | Внутри |
|---|---|---|---|
| `zoom_ira_drawer` | зум тумбы Иры | код кейпада | лист «Реестр отделов» (читается, не забирается); зона «Назад к тумбе» на передней стенке |
| `zoom_wb_drawer` | зум верстака | ёлочный ключик | разводной ключ, впечатанный в арт (не катаут) |

Принцип: открытое состояние ящика — НЕ катаут-заплатка поверх родителя
(чужая перспектива/цвет/масштаб — родовой дефект), а отдельный полноэкранный
кадр. Родительский кадр всегда рисует ящик закрытым; «открыт» выражается
зоной-входом. Переход зум→зум движок умеет; выход из любого зума (ПКМ/Esc)
ведёт в комнату, поэтому у ящика Иры — явная зона возврата к тумбе.

Два признака хотспота, введённые для читаемости этой схемы:
* **enter_zoom** — после срабатывания узла указанный зум открывается сам
  (повернул ключ → уже смотришь в открытый ящик). Иначе отклик на трату
  предмета почти невидим (р.22).
* **leave_zoom** — после срабатывания узла кадр зума закрывается сам
  (взял впечатанный в арт ключ → кадр ящика закрылся; вернуться нельзя,
  поэтому «взятый» ключ в арте никто не увидит) (р.19).

## 2. UI/UX сверх GDD §8.5

* **Архив «БУМАГИ»** (кнопка HUD): панель на две колонки по девять строк —
  всё прочитанное перечитывается в любой момент. Мотив (р.19): улика не
  имеет права исчезать из мира безвозвратно (подарок пропадал вместе с
  биркой Тайного Санты — нарушение never-blind). ПКМ по подарку читает
  бирку, не разворачивая его.
* **Подсветка зон**: удержание пробела подсвечивает интерактив (кнопка
  «ЗОНЫ» в HUD — то же для мыши).
* **Приоритет попадания клика**: hit-список сортируется (1) интерактивные
  зоны раньше фоновых look-осмотров, (2) внутри ранга — меньшая площадь
  раньше. Следствие: look-зона, целиком накрытая интерактивной, недостижима
  — проверять при раскладке зон (известный экземпляр: осмотр штыря двери
  щитовой).
* **Выбор предмета**: клик выбранным предметом по объекту ПРИМЕНЯЕТ его и
  подавляет навигацию (в т.ч. стрелки переходов). ПКМ снимает выбор. Фейл
  применения выбор НЕ снимает (известная шероховатость).
* **Читалка**: ЛКМ листает страницы, на последней ЛКМ закрывает; ПКМ
  закрывает сразу. Закрытие бумаги из архива возвращает в список, не в мир.
* **Сейвы**: единый слот + автосейв после каждого значимого действия;
  запись строго через love.filesystem (unicode-safe; системные os.rename
  на Windows ломаются на кириллических путях профиля — р.23); прежний сейв
  → `.bak`, загрузчик поднимает основной → `.bak` → `.tmp`; отвергнутый
  сейв оставляет игрока на титуле с внятным тостом; «непроходимость из
  этой точки» проверяется солвером при загрузке (предупреждение, не блок).
* **Тосты** — короткие всплывашки (взятие предметов, беды сейва).
* **Дрожь камеры** — состояние героя, лечится по сюжету (валидол+кофе);
  дублирующий выключатель «Убрать тряску» в настройках. Мир не трясётся —
  только плашки UI (решение автора).
* **Идл-реплики** — пул реплик простоя с таймером.

## 3. Подсказки Предка (уточнение GDD)

11 тем × 3 уровня (calm → stern → smug), кулдаун 45 с. Тема выбирается
автоматически: первая незакрытая в порядке приоритета
`t_start → t_utility → t_card → t_pc → t_skud → t_power → t_alarm →
t_bolt → t_calm → t_final → t_secret`. Прямые подсказки — только по кнопке
«СОВЕТ ПРЕДКА» (правило автора). Тема `t_pc` (глифы ПК) выделена из
`t_card` отдельной темой (р.19): расшифровка глифов была третьим пунктом
чужого совета, и до неё никто не дочитывал.

## 4. Звук: схема 2.0.5 (GDD §8.6 расширен)

BGM-менеджер: фоны-лупы (stream) + слои + one-shot-стингеры, переключение
по состоянию мира:

* Фоны: `bgm_title`, `bgm_night_a/b` (ночь, чередование), `bgm_day_a/b`
  (день), `bgm_epilogue`.
* Слои поверх фона: `layer_garland` (гирлянда включена),
  `layer_nervous` (тряска/невроз — глушится после calm_down).
* Стингеры событий: `sting_power` (свет), `sting_solved` (стенд),
  `sting_crown` (корона), `victory`.
* Озвучка действий: щелчки реплик по спикеру (`blip_lap`/`blip_anc`),
  предметные звуки (полный список — каталог `assets/audio/`, 42 файла).
* Музыка/звуки — раздельные выключатели в настройках; всё обязано
  переживать null-audio (headless).

## 5. Движковая графика поверх арта (принцип 9 в действии)

Рендерит движок, в арте этого НЕТ: титульная надпись (арт-лого поставлен в
2.0.1), табличка входной двери, цифры кейпадов, глифы стикера и легенда
плаката, токены дат в документах, подписи щитка и бирки вентилей, снег за
окном, скринсейвер ПК, рыбка в аквариуме (2 фазы), гирлянда (процедурная,
по маске ёлки, ночь/день), LED-грид сигнализации и считывателя (штатные
позиции — данные), стрелка манометра, головка шпингалета, значки статуса
поверх LED (галочка/крест — вектор), маркеры целей и свёрнутой плашки
(вектор — в шрифтах сборки нет «✓»/«▸», см. §7).

## 6. Свето-состояния и катауты (дельта)

* Право открытие двери щитовой на вайде A — интерим-катаут поверх слота
  (ночь/день версии).
* Открытая дверца ЩИТКА на вайде B (р.20): катаут-вырезка открытого щитка
  из зум-арта ×0.33 с тональной подгонкой под ночь/день по якорям
  «стена+тень» (петли слева — согласовано с зумом).
* Пустые тиски после взятия коллектора (р.20): инпейнт-катаут из родного
  арта (гофра-«огрызок» затёрта, шток дорисован клоном).
* Дневная правая треть офиса структурно расходится с ночной →
  у зон правой трети отдельные `rect_day`, у катаутов `pos_day`/`img_day`.
* Ночная подсобка темнее канона сознательно (решение автора, порог гейта
  ослаблен до 8 %).

## 7. Шрифтовой канон (р.19, обязателен при пересоздании)

Три шрифта: PTSans Regular/Bold (диалоги/UI) + Neucha (рукописное).
Каждый символ каждого игрового текста обязан рисоваться ВСЕМИ тремя
шрифтами: движок на отсутствующем глифе молча рисует `.notdef` (в Neucha
он пустой — символ исчезает бесследно). Значки — вектором; стрелки
переходов — словами («В офис», «В щитовую»); типографские спецсимволы
(✓ ▸ → ← ≠ 🤦 и любая кана) — под запретом. Гейт: `tools/check_fonts.py`
с канарейкой.

## 9. Секретный слой (уточнение)

Реликвии: ятаган (повторный обыск ящика стола), значок (под диваном,
нужен длинный сачок), феска (коробка «НГ-2019» с антресоли). Корона —
повторный обыск коробки после фески. Эпилог вариативен от собранного;
полный — с короной. Плашка целей показывает «??? n/3».

## 10. Верификация как часть дизайна (расширение GDD §9)

Пересоздавая игру, пересоздай и стенд: гарантии живут не в коде, а в
конвейере (MIGRATION.md §3). Сверх оригинального DoD добавлены: гейт
шрифтов с канарейкой; verify-листы ВСЕХ видов с гейтом покрытия катаутов
зонами (порог 50 %); letterbox-смок с тремя сменами размера окна по ходу
прогона; 23 негатива (каждый гейт обязан падать на точечной порче и
называть место; движковые признаки enter/leave_zoom, сейв-фолбэки и
бейдж-чек смены портретов — со своими негативами); фаззер дёргает и замки
(покрытие веток обязательное); автоплей кликает через окно (letterbox
пересчёт), а гейт-оракулы питаются промерами арта, не данными зон (урок
№1). Прогоны генератора галереи печатают AUTOPLAY FAIL штатно — их
сторожа требуют победы, которой в галерейном сценарии нет.
