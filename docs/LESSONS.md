# Уроки проекта (пост-мортем багов 2.0.1–2.0.4)

1. **Самосогласованный тест — иллюзия.** Автоплей кликал центры тех же
   ректов, которыми работает hit-тест → сломанные хотспоты проходили
   гаунтлет. Оракул и испытуемый обязаны питаться из разных источников:
   клик-верификация — от промеров арта, не от данных зон.
2. **Геометрия версионируется вместе с артом.** Перегенерация фонов без
   перепривязки зон/катаутов = линейка на ёлке. После любой смены арта —
   verify-листы + silhouette-отчёт (см. validate_scene, WARN-блок).
3. **Экранные API ≠ виртуальные координаты.** setScissor (и любой API в
   координатах окна) не знает про letterbox — бага не видно ровно в
   1920×1080. Смок в «кривом» разрешении (xvfb 1536×864) обязателен.
4. **Инварианты UI — в валидатор с первого дня:** hit-список сортируется
   по площади; центр зоны не перехватывается соседом; min сторона 44px.
5. **Координаты, привязанные к арту, — только в данных.** Хардкод бокса
   скринсейвера в коде — тот же баг, что и зоны, в другом месте.
6. **Интерактивный предмет обязан контрастировать с фоном** (бежевая
   линейка на бежевом столе = блокер при формально корректной зоне).
7. **Живой тестер — часть DoD.** 12 машинных гейтов не заменили вечер
   игры на реальной Windows. Вести docs/QA_JOURNAL.md, смотреть
   verify-листы (tools/gen_verify_sheets.py) перед каждым релизом.
8. **Событию о размере окна не верить — сверять факт.** Встроенный браузер
   iOS (WKWebView, в нём Telegram открывает игру на iPhone) в `resize` отдаёт
   неверный размер, а верный приходит позже без события (WebKit 170595);
   рантайм, меряющий канвас только по событию, застревает — кадр «лёжа» на
   горизонтальном экране (р.27). Тест на такое — заглушка ошибки плюс
   контрольный прогон БЕЗ исправления, который обязан её воспроизвести:
   иначе зелёный тест может не доказывать ничего (урок №1).
