# «Латунный янычар 2.0» — ПОЛНОЕ ПРОХОЖДЕНИЕ (СПОЙЛЕРЫ)

> Единственный файл с решениями. Не входит в поставляемый ZIP.

## Ответы замков

- Код ПК Иры: **5312** (глифы на стикере: ['yatagan', 'crescent', 'drum', 'fez'] по словарю глифов)
- Код тумбы Иры: **4991** (правило из чата + «О компании»)
- Форма СКУД: номер **131383**, отдел **СКЛАД** (пропуск Гены + реестр + приказ)
- Код сигнализации: **1612** (календарь + журнал: правило «ДДММ»)
- Стенд: последовательность **['П открыть', 'К1 открыть', 'К2 открыть', 'С закрыть', 'насос ×7']**, затем насос ×**7** (листок у стенда; в печатной инструкции опечатка: ['П закрыть', 'К1 открыть', 'К2 открыть', 'С закрыть'] — правка в журнале)

## Золотой путь (порядок солвера)

1. Осмотреть главную дверь
2. Взять линейку со стола
3. Поддеть линейкой заклинивший ящик своего стола
4. Взять ручку-шток из ящика
5. Обшарить ящик ещё раз — РЕЛИКВИЯ «Ятаган»
6. Открыть дверь щитовой ручкой-штоком
7. Заметить сачок на шкафу в подсобке
8. Взять указку у KPI-доски
9. Столкнуть сачок указкой через вентиляцию (из офиса)
10. Подобрать сачок с пола подсобки
11. Соединить сачок с указкой → длинный сачок
12. Выудить блестящее со дна аквариума — пропуск Гены
13. Разблокировать ПК Иры
14. Открыть тумбу Иры кодом
15. Заполнить форму СКУД (номер + отдел)
16. Снять сигнализацию кодом
17. Снять ключик-«игрушку» с ёлки
18. Открыть верстак ключиком с ёлки
19. Взять разводной ключ
20. Снять латунный маховик-«экспонат» со стены
21. Насадить маховик на голый шток «П»
22. Собрать давление на стенде
23. Снять коллектор из зажима
24. Коллектор + ключ → трёхгранник
25. Открыть электрощиток трёхгранником
26. Автомат ГЛАВНЫЙ — свет
27. Автомат РОЗЕТКИ
28. Сделать копию пропуска на ксероксе
29. Открыть подарок под ёлкой — открытка и сотня
30. Купить кофе за сотню
31. Взять валидол из аптечки
32. Кофе + валидол — унять тряску
33. Взять смазку «Литол» со стеллажа
34. Смазать и сдвинуть засов (нужны смазка и ключ)
35. РЕЛИКВИЯ: значок под диваном (длинный сачок)
36. Взять швабру с крюком
37. Снять коробку «НГ-2019» с антресоли шваброй
38. Открыть коробку — РЕЛИКВИЯ «Феска»
39. Перетряхнуть коробку — КАРТОННАЯ КОРОНА
40. Провести копией по считывателю
41. Толкнуть дверь — СВОБОДА

## Секретный слой

- Ятаган: обшарить ящик стола Лапидуса повторно.
- Значок «Лучший продавец»: пошарить длинным сачком под диваном.
- Феска: коробка «НГ-2019» с антресоли (нужна швабра).
- Корона: перетряхнуть коробку ещё раз. Носится до конца игры и меняет эпилог.

## Эпилоги

Зависят от числа реликвий (0–3); корона добавляет отдельную финальную реплику. Тексты — в design/texts.json → epilogues.
