## Что это
«Латунный янычар 2.0» — юмористический point-and-click escape-квест (LucasArts-стиль). Санкт-Петербург, офис ООО «ВАЛТЕК», ночь с 31.12.2018 на 01.01.2019. Менеджер Лапидус заперт в офисе; советы даёт Предок — латунный янычар. Ремейк пиксельной v1.0.0. Маркировка 18+ (никотин пассивно), обсценной лексики в игре НЕТ.

## Движок и структура
- **LÖVE 11.5** (Lua/LuaJIT). Виртуальный холст 1920×1080, окно resizable, letterbox в `main.lua` (`letter`, `to_world`). Экранные API (setScissor и т.п.) обязаны учитывать letterbox (`LB` в `scenes.lua`). (р.26) На сенсорном устройстве (флаг `--touch` от веб-оболочки) портретное окно рисует кадр «лёжа» — мир повёрнут на 90° по часовой во всю длинную сторону; экран↔мир только через `scenes.unrotate` / `scenes.to_screen` (ими пользуются клик, scissor снега и бейдж-чек автоплея).
- `main.lua`, `conf.lua`; `src/ui.lua` — UI (инвентарь с выбором предмета, диалоги, цели, читалка, виджеты кейпад/ПК/форма СКУД, меню, BGM-менеджер); `src/scenes.lua` — комнаты/зумы/катауты (`img_day`, `pos_day`, `shadow`, анимации `frames`/`idle`)/снег/скринсейвер; `src/core/state.lua` — состояние/солвер/узлы; `src/touch.lua` — распознаватель касаний (р.25: тап = ЛКМ, удержание 0,45 с = ПКМ, сдвиг — отмена; чистый Lua, юнит-тест `tools/test_touch.lua`); `src/autoplay.lua` — прогон сценариев через реальный UI (op select_item есть; р.25 — ops tap/hold/drag/finger_down/finger_up, режим `input touch`).
- `design/*.json` **генерируются** — руками не править: `tools/gen_scene.py`, `gen_texts.py`, `gen_puzzles.py` → правь генератор + regen.
- **Исключение — `puzzles.json`.** `gen_puzzles.py` берёт ответы (коды, глиф-карту, порядок стенда) из криптослучайного источника: голый запуск поверх готового файла сменил бы их молча, и с игрой разошлись бы `WALKTHROUGH_SPOILERS.md`, verify-листы, скриншоты и сейвы автора. Штатный regen — `python3 tools/gen_puzzles.py --pin`: структура заново, ответы прежние (тождество проверено байт-в-байт). Новые ответы только осознанно: `--new-answers --force`, воспроизводимо `--new-answers --seed N`. Голый запуск скрипт отклоняет сам (rc=2) и перед записью кладёт `puzzles.json.bak-<время>`; сид и значения в консоль не печатаются (канон спойлеров).
- `assets/gfx/` (rooms, cutouts st_*, zooms, icons, portraits, ui, fonts), `assets/audio/` (bgm_*, layer_*, sting_*, звуки). `tools/` — генераторы/валидаторы/гейты (+ check_fonts, gen_verify_sheets, gen_gallery, gen_vents_r7, gen_garland, gen_keypad_digits, gen_r9_cutouts, gen_r10_assets). `docs/` — BUILDLOG, QA_JOURNAL (журнал замечаний автора по раундам — ВЕСТИ), LESSONS (обязательно прочесть), GAME_TEXTS_FULL (дамп, `tools/gen_texts_dump.py`), WALKTHROUGH_SPOILERS, `docs/design/` (исходный GDD, ASSET_SPEC, принципы проекта — бывший `handoff/`, бинарные дубли приёмки удалены в р.24). `web/` — оболочка веб-версии (`web/index.html`). `work/` — артефакты, карантин `orig_*`, `shots/`, `gallery/`, `web_shots/`. `dist/` — релизы (`dist/web/` — веб-сборка). gitignore: work/, dist/, *.love, __pycache__/, node_modules/.

## Запуск и тесты
- `love .` · смок `love . --selftest` · гаунтлет `love . --autoplay work/autoplay_full.json`.
- Headless: `xvfb-run -a -s "-screen 0 1920x1080x24" love . ...`; ускорение libfaketime: `FAKETIME="+0 x4" LD_PRELOAD=.../libfaketime.so.1 DONT_FAKE_MONOTONIC=0` (вотчдог 10 с сим-времени/шаг; x4–x5 безопасно).
- **DoD-конвейер** (`MIGRATION.md §3`) целиком перед релизом: test_state → test_touch → GATE1 → gen_scene+gen_texts+gen_texts_dump → GATE2 → check_fonts → selftest → чистый сейв (`%APPDATA%\LOVE\BrassJanissary2` / `~/.local/share/love/BrassJanissary2`) → gen_autoplay → гаунтлет → gates.py → fuzz 3×25000 → trace_solver+clue_audit → gen_walkthrough → gen_verify_sheets (все 16 видов, смотреть глазами) → letterbox-смок (окно меняет сам сценарий: 1600×1000 / 1920×864 / 1500×900; ключом xvfb окно не ограничить) → сенсорный гаунтлет `work/ap_touch.json` (р.25: вся игра пальцем, без мыши и клавиатуры; р.26: телефон вертикально 960×2080 с кадром «лёжа» до бейджей включительно → 1600×740 → 1366×1024) → `tools/test_negatives.py` (негативы; 43 кейса, ≈6 мин, `--fast` без движка).
- **Гейт шрифтов** `tools/check_fonts.py`: каждый символ из `design/texts.json`, `design/scene.json` (имена зон, подписи щитка — с р.24) и строковых литералов Lua обязан рисоваться ВСЕМИ тремя шрифтами. Движок на отсутствующем глифе молча ставит `.notdef` (в Neucha он вообще пустой — символ исчезает бесследно), поэтому раунд 19 нашёл шесть таких дыр разом: «✓» у закрытых целей, «▸» на свёрнутой плашке, «→»/«←» на дверных плашках, «🤦» в чате, «ト» в караоке. Значки — вектором, стрелки — словами. Правило «во всех шрифтах»: одна реплика уходит и в диалог (PTSans), и в бумагу (Neucha), связать строку со шрифтом статически нельзя.
- Галерея всех экранов: `tools/gen_gallery.py` → `work/gallery/` (49 кадров + контактные листы) — прогонять после визуальных правок, автор ревьюит по ней.
- Сборка релиза: `docs/BUILDLOG.md` Фаза 6 — `work/game.love` (zip -9: main.lua conf.lua src assets design) → fuse с официальным love.exe 11.5 win64 → portable-пакет → `dist/...-win64-portable.zip` → **SHA-256** → wine-гаунтлет из кириллического пути (WINEPREFIX в $HOME, LANG=C.UTF-8).
- **Веб-версия** (р.24, с согласия автора): `python3 tools/build_web.py [--zip] [--serve 8000]` → `dist/web/` — love.js (LÖVE 11.5 в WebAssembly, вариант compatibility; файлы рантайма с закреплённого коммита Davidobot/love.js, сверка SHA-256), фоны перекодированы в JPEG q90 4:4:4 под теми же именами (`--lossless` — оставить PNG). Смок: `NODE_PATH=$(npm root -g) node tools/web_smoke.js http://127.0.0.1:8000/` (Playwright: загрузка без ошибок/алертов, ресайз, сейв переживает закрытие браузера, р.25 — сенсорный экран 915×412: тап = ЛКМ, удержание = ПКМ, канвас под вкладку; р.26 — телефон вертикально 412×915 с кадром «лёжа» и запуск «внутри Telegram» с подменённым SDK; р.27 — Telegram на iPhone: поворот с заглушкой ошибки WebKit 170595, причём контрольный прогон с оболочкой без сверки кадра обязан эту ошибку воспроизвести; кадры в `work/web_shots/`). Публикация — вручную: Actions → «Веб-версия (GitHub Pages)» (`.github/workflows/web.yml`). Особенности веба: чтение файла только после `love.filesystem.getInfo` (в love.js чтение отсутствующего файла роняет движок, pcall не спасает); «Выход» и «Полный экран» в вебе скрыты (`WEB` в `src/ui.lua`); Lua там 5.1, не LuaJIT — без `goto`, `bit`, `ffi`, `\x`-эскейпов; сейвы в IndexedDB синхронизирует `web/index.html` (рантайм делает это только по beforeunload); касание приходит как ЛКМ с `istouch=true` (`love.mousepressed/mousereleased/mousemoved`) — его разбирает `src/touch.lua`, мышь идёт прежним путём; минимум окна 960×540 в вебе снят (`conf.lua`, `love._os == "Web"`) — иначе на телефоне кадр сплющивался. **Telegram Mini App** (р.26): оболочка узнаёт запуск в Telegram по параметрам в адресе после «#» (`tgWebAppData`…), только тогда грузит SDK telegram.org и просит весь экран (Bot API 8.0+), отключает свайп-закрытие (7.7+), красит рамку в чёрный и фиксирует ориентацию, как только экран горизонтальный (`lockOrientation` держит текущую); канвас отступает от кнопок Telegram по `--tg-safe-area-inset-*` и `--tg-content-safe-area-inset-*`. На телефоне в обычном браузере «Играть» открывает весь экран и просит альбом (`screen.orientation.lock`, где умеет). **Размер кадра** (р.27) оболочка сверяет с канвасом сама — ResizeObserver и опрос раз в 200 мс, при расхождении досылает рантайму `resize`: love.js меряет канвас только в этом событии, а встроенный браузер iOS (WKWebView — так Telegram открывает игру на iPhone) отдаёт в нём неверный размер (ошибка WebKit 170595, при повороте — почти квадрат), верный появляется позже уже без события; без сверки кадр застревал, и игра рисовалась «лёжа» и сплющенной на горизонтальном экране. В вебе игра печатает в консоль `BJ2 FRAME Ш×В стоя|лёжа` при каждой смене кадра (по ней смок).

## Правила
- Координаты арта — только в данных (gen_scene), не в коде (см. docs/LESSONS.md).
- Зоны: min сторона 44px; hit-список сортируется по площади; центры не перехватываются (следит GATE2).
- «Клик по арту проверять промерами (numpy), не глазами»: кропы с сеткой, verify-листы; правая треть офиса день/ночь расходится → rect_day/pos_day/img_day.
- Оригиналы правленных ассетов — карантин `work/orig_*` ДО правки.
- Гейт яркости ночной комнаты B ослаблен до 8% сознательно (тёмная подсобка — решение автора, р.7).

## Нельзя менять без согласия автора
1. **Спойлеры** — только в `design/puzzles.json` и `docs/WALKTHROUGH_SPOILERS.md`; в чат/отчёты/коммиты — никогда.
2. **Поставка — portable ZIP** + SHA-256 и (с 2026-10-03, по просьбе автора) веб-версия в браузере (`tools/build_web.py`, GitHub Pages). Никаких инсталляторов.
3. Мат не возвращать (гейт мат-доли ослаблен снизу сознательно).
4. Вывеска «VALTEC» на титуле — решение автора (отступление от MIGRATION §5.2).
5. Механику «выбрать предмет → применить на объект» не упрощать до «срабатывает от наличия».
6. Прямые подсказки Предка — только по кнопке «СОВЕТ ПРЕДКА».
7. Релизы — только по явной команде; версию поднимать, если предыдущая уже была у автора.

## Режим работы с автором
Автор (Lao) — владелец и единственный тестер (реальная Windows). **Диалоговый режим:** сомнение → остановись и спроси. Замечания — в `docs/QA_JOURNAL.md` раундами со статусами (✔/✦ нужен ассет+промпт/✋ автор сам/⏳). ## Известные особенности
- Автоплей самосогласован (кликает центры зон из данных) — совпадение с артом доказывают только verify-листы/промеры.
- Звук обязан переживать null-audio (headless).
- Правая треть НОЧНОГО офиса: арт-детали ~на 50px правее хотспот-данных (пред-существующий рассинхрон, см. QA_JOURNAL р.10).
- Крупные правки генераторов — атомарными скриптами с проверкой парсинга; после любой правки — regen + гейты.
- Git через смонтированную папку (Cowork-мост) не умеет ни `unlink`, ни переименования поверх существующего файла. Отсюда два следствия. Первое: даже читающие команды оставляют `.git/index.lock` и блокируют следующую — читать с `GIT_OPTIONAL_LOCKS=0`, залежавшиеся `*.lock` и `.git/objects/*/tmp_obj_*` не удалять (`rm` запрещён), а переносить в `../_to_delete/`. Второе, злее: `git add` не может положить новый индекс поверх старого — тихо не стажит ничего, а в неудачный день сносит `.git/index` совсем, и тогда `git status` показывает ВСЕ файлы как удалённые. Пугает зря: файлы целы, нет индекса — не более. Рецепт (р.18, коммит e687008): держать индекс вне монтирования — `export GIT_INDEX_FILE=/tmp/bj_idx` и `git read-tree HEAD`, дальше `add`/`status`/`commit` обычным порядком (объекты и refs пишутся нормально, только сорят `tmp_obj_*`), в конце вернуть индекс на место — `cp /tmp/bj_idx .git/index`, иначе автор на Windows увидит то самое «всё удалено». Приёмка: пустой `git status --porcelain` и чистый `git fsck`.
