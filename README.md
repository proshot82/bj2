# Латунный янычар 2.0

Юмористический point-and-click escape-квест в духе LucasArts. 18+ (пассивное
курение в кадре), обсценной лексики нет. Ночь с 31.12.2018 на 01.01.2019,
Санкт-Петербург, офис ООО «ВАЛТЕК». Менеджер Лапидус заперт в офисе, советы ему
даёт Предок — латунный янычар. Это ремейк пиксельной v1.0.0, движок — LÖVE 11.5.

## Как играть

- **Windows** — portable ZIP; сборка описана в `docs/BUILDLOG.md`, «Фаза 6».
- **Браузер** — веб-версия на love.js: на компьютере — мышь и клавиатура, на
  телефоне и планшете — пальцем (касание — действие, долгое касание — осмотр и
  «назад», как правый клик; коды и номер формы — экранными кнопками). На
  телефоне игра всегда горизонтальная (вертикально держимый телефон получает
  кадр «лёжа») и открывается на весь экран, в том числе как мини-приложение
  Telegram.
  Публикуется только вручную: Actions → «Веб-версия (GitHub
  Pages)» → Run workflow (`.github/workflows/web.yml`). Предварительно один раз
  нужно включить Settings → Pages → Source: «GitHub Actions». Для этого
  репозитория адрес будет `https://proshot82.github.io/bj2/`. Локальная сборка:
  `python3 tools/build_web.py --serve 8000`.
- **Из исходников** — `love .` (нужен LÖVE 11.5).
