# «Латунный янычар 2.0» — Главный дизайн-документ (GDD)
Ремейк v1.0.0 в новом стиле. Статус: **design-final** — по этому документу
строится спецификация ассетов (`ASSET_SPEC.md`), затем — полностью автономная
сборка после загрузки ассетов. Ответы замков в GDD отсутствуют принципиально:
они генерируются на сборке и живут только в `puzzles.json` и
`WALKTHROUGH_SPOILERS.md`.

---

## 0. Что меняем относительно v1 (по критике)
1. **Темно и не видно** → светлый cartoon-стиль 1920×1080; «ночь» = дежурное
   освещение (читаемое, холодное), «день» = тёплое яркое. Контраст-гейт для
   фонов и интерактива входит в верификацию.
2. **Свалка в одну линию** → **два экрана-комнаты** + **зум-виды** устройств.
   Композиция каждой стены: 5–7 крупных смысловых пятен, воздух между ними,
   второстепенка — внутри зумов, а не на общем плане.
3. **Ходячий герой** → убран полностью. Вид от первого лица; персонажи
   существуют только как говорящие головы-портреты.
4. **«Кто говорит?»** → жёсткая привязка: у каждой реплики обязательный
   speaker; портрет + **плашка-имя** («ЛАПИДУС» / «ПРЕДОК») + разный цвет
   рамки диалога (латунь / холодная сталь). Сборка падает, если у строки нет
   спикера или у спикера нет портрета данной эмоции.
5. **Головоломки-виньетки** → единый механизм (§5): каждая ветка проходит
   через обе комнаты, побочных «одноходовок» нет.

## 1. Высокоуровневая рамка
- Жанр: point-and-click escape (первое лицо, экраны-стены, зумы).
- Сеттинг прежний: офис продаж «ВАЛТЕК», Санкт-Петербург, ночь 1 января.
- Герой: **Лапидус** (мононим — бегущая шутка), потомок янычар,
  усы-барометр. Подсказчик: **Предок** (воображаемый янычар).
- Тон: 18+, усталый злой юмор, мат 15–35 % реплик, янычарский пафос невпопад.
- Цель: выйти из офиса. Секретная цель: собрать 3 реликвии янычара
  (ятаган, значок, феска) + бонус-корона. Эпилоги ×4 (0–3 реликвии).
- Движок: LÖVE 11.5, Lua. Разрешение арта 1920×1080, letterbox-масштаб.
- Почему не позвонить: телефон Лапидуса — 3 % батареи, сети нет; работает
  только фонарик (лор-обоснование свето-независимых зумов) — и это герринг.

## 2. Экраны
### Экран A — «Офис» (стартовый)
Слева направо, 7 смысловых пятен:
1. **Окно** (двор в снегу; герринг-эскалация «выпрыгнуть»).
2. **Диван** + журнальный столик; на подлокотнике караоке-список (док);
   **под диваном** — щель (реликвия-значок, достаётся длинным сачком).
3. **Ёлка** (гирлянда выключена/включена — управляется автоматом из щитовой!);
   на ветке — **ключик-«игрушка»** с биркой; под ёлкой **подарок**
   (внутри открытка «на кофе» с сотней; бирки Тайного Санты — док).
4. **Рабочий блок Иры**: ПК (зум), кодовый **ящик** (зум-кейпад);
   над столом **календарь** (док) и **плакат по охране труда** (док-легенда).
5. **Рабочий блок Лапидуса**: стол, **линейка**, запертый ящик
   (поддевается линейкой: внутри **дверная ручка-шток**, глубже — ятаган);
   над столом **KPI-доска** с воткнутой **указкой**.
6. **Аквариум на тумбе** (зум: на дне пропуск Гены; рыбка), рядом к тумбе
   ничего не прислонено — сачок теперь в щитовой (§5.D).
7. **Выходная зона**: главная **дверь** (зум: табличка «Закрыто по 8.01»,
   **засов**), **считыватель** (LED), **панель сигнализации** (зум-кейпад),
   **домофон** (герринг), над дверью EXIT.
Плюс: **дверь в щитовую** (правый край, без ручки — торчит квадратный шток),
**вентрешётка** высоко над шкафом-гардеробом (пятно 4½), **кофемашина**
(между 3 и 4; обесточена отдельной линией), **копир** (у блока Иры).

### Экран B — «Щитовая-подсобка»
Слева направо, 6 пятен:
1. **Электрощиток** (дверца под трёхгранник; зум: 6 автоматов + карман со
   **схемой**-доком).
2. **Верстак**: ящик с **висячим замочком** (ключик — на ёлке!; внутри
   **разводной ключ**), на столешнице **«Журнал испытаний»** (док).
3. **Испытательный стенд** (зум): магистраль, 4 вентиля **П/К1/К2/С**
   (на П нет маховика), **манометр**, ручной **насос**, **зажим с
   коллектором**, кнопка СБРОС, приколот **листок-инструкция** (док с правкой).
4. **Стеллаж**: полка со **смазкой**, хлам; **антресоль** наверху —
   коробка «НГ-2019» (зум после снятия: **феска**, потом **корона**);
   достаётся **шваброй-крюком**.
5. **Шкаф уборщицы**: **швабра**, ведро; **аптечка** на дверце (**валидол**).
   На шкафу сверху лежит **сачок без ручки** — из подсобки не достать;
   **вентрешётка** в стене точно над шкафом (сквозная с офисом!).
6. **Бойлер + раковина** (герринги: «слить воду», вентиль-обманка),
   дверь обратно в офис.

Навигация: клик по двери/стрелкам у краёв — мгновенная смена экрана
(после открытия щитовой — двусторонняя).

## 3. Зум-виды (полноэкранные, свето-независимые: «подсветил телефоном»)
A-офис: ПК-экран; кейпад ящика Иры; панель сигнализации; аквариум; ёлка
(крупно ветки+подарок); дверь+засов; ящик Лапидуса (после вскрытия).
B-подсобка: щиток (внутренности); стенд; верстак+ящик; антресоль; шкаф
уборщицы. Итого 12 зумов. Выход из зума — ПКМ/кнопка «назад».

## 4. Предметы инвентаря (18)
линейка; **ручка-шток**; указка; сачок; **длинный сачок** (комбо
указка+сачок, указка расходуется); пропуск Гены; ксерокопия (копир,
опционально); ключик-игрушка; разводной ключ; маховик (витринного шкафа
больше нет — маховик закреплён декоративно **на стене офиса между пятнами
6–7 как «экспонат»**, снимается); трёхгранник; смазка; сотня; кофе; валидол;
швабра; феска (реликвия); ятаган (реликвия); значок (реликвия); корона.
ЛКМ — взять/применить/комбинировать; ПКМ по предмету — крупный вид/документ
(пропуск = читаемый док). «Принять успокоительное» = **комбо валидол+кофе
в инвентаре** (первое лицо — на себя не «кликаем»).

## 5. Паззл-механизм (веб зависимостей; без ответов)
Обозначения: [A]/[B] — комната; → needs.

### D0. Открытие подсобки (ранний ключевой ход)
survey_door[A] (осмотр главной двери — активирует панель целей)
ruler[A] → pry_drawer[A] (ящик Лапидуса) → **handle**(ручка-шток)
handle → **open_utility**[A→B] (надеть на квадрат, дверь щитовой открыта)
pry_drawer (второй обыск) → **relic_yatagan** (секрет)

### D1. Ветка «Пропуск» (A↔B через вентиляцию)
see_net[B] (осмотр верха шкафа: «сачок, не достать») + pointer[A] (указка)
→ **push_net**[A] (в вентрешётку офиса: сачок падает в подсобке)
→ take_net[B] → longnet (комбо) → **fish_card**[A, зум аквариума]
доки: стикер под клавиатурой (в зуме ПК) + плакат ОТ → **pc_unlock** (PIN)
pc_unlock → приказ №7 (**read_order**), чат, «О компании», словарь
чат+«О компании» → код ящика Иры → **drawer_open** → реестр (док)
карта (номер) + реестр (отдел) + read_order → форма СКУД-2 → **card_active**

### D2. Ветка «Сигнализация» (короткая, параллельная)
календарь[A] + чат[ПК] → код → **alarm_off**

### D3. Силовая ветка (самая длинная, A→B→A)
ключик-игрушка[A, ёлка] → **open_workbench**[B] → разводной ключ
маховик[A, стена] → (зум стенда) листок-инструкция + журнал[B]
→ порядок вентилей + качки насосом → **bench_solved** → зажим отдаёт
**collector** → комбо разводной+коллектор → **trikey** (трёхгранник)
trikey → **open_panel**[B] → схема (док) → главный автомат → **power_on**
(свет day в ОБЕИХ комнатах; считыватель просыпается)
отдельный автомат «РОЗЕТКИ» → **sockets_on** (оживает кофемашина[A])

### D4. Ветка «Руки»
подарок[A] → сотня; sockets_on → кофемашина+сотня → **coffee**
аптечка[B] → валидол; комбо → **calm_down** (тряоска интерфейса ×0.25→0)

### D5. Ветка «Засов»
смазка[B] + разводной[B] → зум двери → **bolt_free**

### D6. Секреты
longnet → под диваном → **relic_badge**
швабра[B] → антресоль → box_down → **relic_fez** → (ещё раз) **crown**

### Победа
door_open ← survey_door + card_active + power_on + alarm_off + bolt_free
+ calm_down. Катсцена: дверь-оверлей «открыто», марш, итоги, эпилог по
реликвиям (0/1/2/3).

### Свойства графа (гейты сборки)
- Узлов ≈ 48–52 (без доков), обязательных 30–34; глубина главной цепи
  D3 = 10 звеньев; одновременно открытых обязательных нитей 3–4.
- **Never-blind**: каждый ввод/действие имеет доступную ранее улику
  (документ или осмотр); каждый кодовый замок — **≥2 источника**.
- Каждая из веток D1–D5 пересекает обе комнаты минимум одним ребром
  (формальная проверка на сборке: cross-room edges ≥1 на ветку).
- Кодовые панели честные: верный код принимается всегда; конкретные
  значения задаются на сборке (в арте кодов нет — §8.3).

## 6. Документы (17)
ПК: стикер-PIN (глифы), чат отдела, приказ №7, «О компании», словарь
сокращений, форма СКУД-2. Офис: плакат ОТ (легенда глифов), календарь,
караоке-список, бирки Санты, открытка «на кофе», пропуск Гены (предмет-док),
реестр отделов (из ящика). Подсобка: журнал испытаний, листок-инструкция
стенда (с рукописной правкой!), схема щитка, инвентарная бирка на швабре
(гэг). Читалка: бумага + латунные уголки, страницы, **весь текст рендерится
движком** поверх пустых «бумажных» подложек (§8.3).

## 7. Герринги и гэги
Окно (3 ступени), домофон (мёртв/«весел» после питания), огнетушитель,
телефон 3 % («позвонить»), бойлер/раковина (2), автоматы-обманки в щитке:
«ЁЛКА» (включает гирлянду в офисе — видимый cross-эффект!), «СРВ», «РЕЗЕРВ».
Idle-реплики каждые ~75 с; невроз-осмотры до calm_down.

## 8. Презентация и техтребования
### 8.1 Рендер
1920×1080 фоны, letterbox, без пиксель-инварианта. Два состояния света
только у комнатных вайдов; зумы и катауты — единые. Ночь обязана держать
контраст: гейт — читаемость силуэтов интерактива (авто-проверка яркостных
дельт по маске хотспотов ≥ порога) + WCAG ≥7:1 для UI-текста.
### 8.2 Слои сцены
Вайд рисуется **без съёмных предметов и без изменяемых состояний**;
каждый съёмный предмет/состояние — отдельный прозрачный катаут с якорем
(двери откр/закр, решётка снята, сачок на полу, гирлянда ON — оверлей,
LED — оверлеи, засов 2 состояния, коробка на полу и т.д.). Позиции — в
`scene.json` v2. Идл-анимации: 2–4 кадровые катауты (рыбка, пар, гирлянда,
скринсейвер, снег за окном, LED).
### 8.3 Типографика
Никакого сюжетного текста в генерируемом арте (коды, даты, номера, легенды).
Все таблички/бумаги в арте — чистые. Движок печатает текст (PT Sans + рукописный
слой для «правок»). Это развязывает генерацию ассетов и значения ответов.
### 8.4 Диалог
Плашка снизу: портрет 512×512 (в UI ~256), **имя-бейдж**, typewriter
40 симв/с, блипы 2 голосов. Эмоции: Лапидус ×8, Предок ×4 (calm, proud,
stern, smug-новая). Ассерты сборки: (a) каждая реплика имеет speaker+emo,
(b) для пары speaker+emo существует портрет, (c) в автоплее скриншот-чек
подсказки: на кадре hint-реплики бейдж = «ПРЕДОК».
### 8.5 UI
Панель целей (5 + секретная «??? N/3»), инвентарь-полоса, кнопки «Совет
Предка», ПАУЗА; SPACE — подсветка хотспотов текущего экрана; стрелки
навигации; курсор-состояния (обычный/действие/переход/зум).
### 8.6 Аудио
Перенос из v1 (эмбиент 150 с бесшовный, марш, 23 SFX, блипы) + новые:
переход экрана, зум-in/out, падение сачка, швабра-крюк, дверь щитовой.

## 9. Верификация (Definition of Done сборки)
Selftest (загрузка манифеста ассетов: каждый файл существует, размер по
спеке ±0, альфа у катаутов), солвер ядра до победы, автоплей-гаунтлет через
реальный UI (оба экрана, все зумы, ≥7 негативов, сейв/континью, реликвии,
проверка бейджа спикера), фаззер 3×25 000, контраст-гейты (§8.1),
cross-room-гейт (§5), wine из кириллического пути, portable-ZIP без
инсталлятора, SHA-256. Ответы — только в puzzles.json/WALKTHROUGH.

## 10. Пайплайн проекта
(1) этот GDD → (2) `ASSET_SPEC.md` → (3) пользователь генерирует и загружает
ассеты → (4) автономная сборка по UNATTENDED-директиве без единого вопроса
→ (5) отчёт + портативный ZIP. Правки дизайна после (3) — только новым
циклом спеки.
