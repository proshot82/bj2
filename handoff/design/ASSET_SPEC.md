# «Латунный янычар 2.0» — ASSET_SPEC.md
Спецификация графики для внешней генерации. Формат: PNG. Прозрачность —
обязательна там, где указано «альфа»; если генератор не отдаёт прозрачный
фон — заливка **чистой маджентой #FF00FF** (я вырежу автоматически).
Никакого сюжетного текста в арте (коды/даты/номера/легенды) — все таблички
и бумаги ЧИСТЫЕ, текст печатает движок. Декоративные надписи-«шум» допустимы,
но не читаемые крупно.

## 0. Стиль-рамка (единая для всех файлов)
Cartoon для взрослых: чистый контур средней толщины, мягкая заливка,
2-тоновые тени, лёгкая текстура; пропорции слегка утрированы; настроение —
уютно-обшарпанный офис 2010-х. Палитра: тёплые латунь/дерево/красный акцент
+ холодные ночные синие. «Ночь» = дежурный свет: холодная, НО светлая
(средняя яркость кадра ~45–55 %), самосветы (экраны/LED/EXIT/окно). «День» =
тёплый верхний свет, яркость ~65–75 %. Композиция вайдов: 5–7 крупных пятен,
между ними воздух; линия пола ~78 % высоты кадра; лёгкая перспектива
«смотрю на стену», без экстремальных ракурсов.

Жёсткие требования к вайдам:
- Пары night/day — ОДИН ракурс и раскладка (перегенерация допустима,
  совпадение по силуэтам ≥ визуально идентично).
- НЕ рисовать на вайде: съёмные предметы и изменяемые состояния из §3
  (места под них оставить «пустыми», напр. голый квадратный шток вместо
  ручки, пустой крюк без швабры, ветка без ключика, стена офиса с
  крепёжной пластиной без маховика, верх шкафа подсобки ПУСТОЙ).
- Обязательные статичные элементы офиса: окно, диван+столик, ёлка (гирлянда
  НЕ горит — отдельный оверлей), подарок НЕ рисовать (катаут), два рабочих
  блока, календарь+плакат (чистые листы с рамками), аквариум на тумбе
  (без пропуска на дне — катаут блика), кофемашина, копир, шкаф-гардероб
  с вентрешёткой над ним, зона выхода (дверь с чистой табличкой, считыватель,
  панель сигнализации, домофон, EXIT), дверь щитовой с квадратным штоком.
- Щитовая: щиток (дверца ЗАКРЫТА), верстак с ящиком (замочек ВИСИТ —
  отдельный катаут снятого нет: замочек рисовать, т.к. состояние «открыт»
  = зум), стенд целиком (вентиль П БЕЗ маховика — голый шток), стеллаж
  с антресолью (коробку НЕ рисовать), шкаф уборщицы (двери закрыты),
  вентрешётка над шкафом, бойлер+раковина, дверь в офис.

## 7. Сводка и нейминг
Всего: 4 вайда + 12 зумов + ~34 катаута + 20 иконок + 13 портретов +
6 разных = **~89 файлов**. Имена — строго как в таблицах (латиница,
snake_case). Загрузка: одним ZIP или пакетами по разделам; вместе с файлами
приложить (не обязательно) seed/промпты для повторяемости. После приёмки я
прогоняю авточек: размеры, альфа/мадженты, парность night/day, комплектность
по манифесту — отчёт с недостающими/бракованными позициями, затем стартует
автономная сборка.
