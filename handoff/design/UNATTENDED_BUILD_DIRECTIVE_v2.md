## 1. Непреложные правила (нарушение = провал сборки)
1. Первое лицо, БЕЗ ходячего героя. Персонажи — только портреты.
2. **Портрет = спикер**: у каждой реплики speaker+emotion; плашка-имя
   («ЛАПИДУС»/«ПРЕДОК»), разный цвет рамки; сборка падает на реплике без
   спикера/портрета; автоплей делает скрин-чек смены портрета на подсказке.
3. Ответы замков НИКОГДА не печатаются в чат/отчёты — только
   `design/puzzles.json` и `docs/WALKTHROUGH_SPOILERS.md`.
4. Сюжетная типографика — только движком поверх чистого арта (PT Sans +
   «рукописный» слой правок); в арт ничего не врисовывать.
5. Канон интерпретации арта = INTAKE_REPORT §5 (столы, двери, панели,
   якоря коробки/сачка/швабры/маховика, зум-only стенд).
6. Раздельные якоря `pos_night/pos_day` для катаутов выходной зоны офиса
   (LED считывателя, сигнализация, накладка штока) — калибровка по обоим
   кадрам, контрольная скрин-пара в гаунтлете.
7. Portable ZIP, без инсталляторов. Wine-прогон из пути с кириллицей
   и пробелами обязателен.
8. `room_utility_night` не осветлять; вместо этого — контраст-гейт
   силуэтов интерактива (люма-дельта по маске хотспотов ≥ порога).

## 3. Фазы (строго последовательно, git-коммит после каждой)
### Фаза 0 — среда
LÖVE 11.5 (linux) + love-11.5-win64 дистрибутив + PT Sans (Regular/Bold,
OFL). Селфтест-заглушка окна под xvfb.
### Фаза 1 — логика
`design/puzzles.json` по GDD §5: ~50 узлов, ветки D0–D6, ответы замков
сгенерировать здесь (в файл), clue_sources ≥2 на каждый код.
Валидатор: never-blind полный обход; глубина главной цепи ≥9;
одновременных обязательных нитей 3–4 на протяжении ≥60 % прохождения;
**cross-room-гейт**: каждая ветка D1–D5 содержит ≥1 ребро A↔B; реликвии
3+корона; герринги ≥6. GATE1 PASS обязателен.
### Фаза 2 — сцены и тексты
`design/scene.json`: обе комнаты (вайды night/day), 12 зумов, хотспоты
(прямоугольники ≥44 px по меньшей стороне на 1080p), катауты с якорями
(включая pos_day-исключения), idle-анимации (рыбка-дрейф, пар, снег,
скринсейвер, гирлянда-overlay, LED), навигационные стрелки, курсор-зоны.
`design/texts.json`: ~300+ реплик (мат 15–35 %), каждая {s,e,t};
осмотры first/repeat/neurotic; доки (17) с [GLYPH]-токенами; подсказки
Предка по темам с 3 тирами; opening/victory/эпилоги ×4; UI-строки.
Гейты: walkability не нужен (нет ходьбы) → вместо него **reachability
зумов** (каждый зум открываем с вайда), лексика-линт, спикер-линт.
### Фаза 3 — движок
Рендер: вайд по свету → катауты (hide_on/show_on/frame_by, per-state pos)
→ idle-анимации → оконный UI. Зум-стек (вайд→зум→модалка-ввод), клавиша
Esc/ПКМ — назад. Инвентарь (ЛКМ select/combine, ПКМ — имя/док), кейпады,
форма СКУД-2, щиток (6 автоматов: главный, РОЗЕТКИ, ЁЛКА-гэг, 3 обманки),
стенд (красн. вентили-катауты, порядок+сброс, насос, манометр-стрелка
движком, зажим-коллектор), читалка (paper_reader + движковый текст +
глифы), панель целей + «??? N/3», «Совет Предка» (интро→темы→тиры,
кулдаун 45 с), сейв/автосейв/континью, настройки (муз/звук/фуллскрин).
Курсоры из cursors/ по контексту. `--selftest` и `--autoplay <json>`
с вотчдогами и errorhandler→exit.
### Фаза 4 — гаунтлет
Автоплей ≥250 шагов через реальный UI: полное прохождение, ≥7 негативов,
все доки до вводов, сейв/континью, реликвии+корона, подсказки (скрин-чек
бейджа «ПРЕДОК»), герринги, ЁЛКА-автомат (гирлянда-оверлей на скрине),
день/ночь пары выходной зоны (якорь-контроль), ≥14 скриншотов.
Пиксель-гейты: контраст UI ≥7:1; силуэт-гейт utility_night; отсутствие
маджента-пикселей (R>200∧B>200∧G<80) на всех скринах.
### Фаза 5 — фаззер и аудит
`fuzz_state.lua` 3×25 000 op (без исключений, фронтир жив, round-trip
сериализации, доигрывание солвером ≤300). Маскированный clue-аудит.
### Фаза 6 — упаковка и wine
game.love → fuse с love.exe → папка с DLL/лицензиями → README RU (18+,
управление: ЛКМ/ПКМ/Space/H/Esc, стрелки-переходы; «Убрать тряску»),
LICENSE (MIT+zlib+OFL), VERSION=2.0.0, WALKTHROUGH_SPOILERS.md.
Wine из «/tmp/Тестовая папка 2.0 (проверка)/»: --selftest rc=0 и полный
--autoplay rc=0. ZIP `BrassJanissary-2.0.0-win64-portable.zip`, SHA-256.
